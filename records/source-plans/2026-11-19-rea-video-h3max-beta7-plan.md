## 1. End-to-End 4-Stage Pipeline Architecture

1. **Stage 1 — Forensic Video Breakdown (CPU-only, X3 or AlienPC):** Run `rea-video decompose <clip.mp4> -o <out_dir> --lang en` (explicit `--lang en` is mandatory because `rea-video` defaults to `--lang zh`; installs in an isolated `uv` venv with `.[asr]` for speaker stems `stems/voice_S1.wav` + ASR dialogue and ~67 MB UVR / ~149 MB BandIt v2 stems; 0 MB GPU conflict). Outputs `breakdown.json`, `VIDEO.md`, cut shot clips, keyframes, and separated audio stems.
2. **Stage 2 — Beta 7 Prompt Compilation & Hygiene (EVO-X3, 0 MB AlienPC LLM VRAM):**
   - `h3max_bridge.py` reads structured `breakdown.json` (never regex-scraping `VIDEO.md`), snaps shot packs to ComfyUI's **17k+5 24 FPS frame grid** (`124f = 5.17s`, `192f = 8.0s`, `243f = 10.13s`, `362f = 15.08s` max; <= 15 s cumulative audio), and strips audio (`ffmpeg -i shot.mp4 -an -c:v copy shot_noaudio.mp4`) from motion-only `<Video N>` clips so ComfyUI's `MiniMaxH3ReferenceToVideo` does not shift `<Audio N>` indices ahead of standalone vocal stems.
   - Calls X3 `llama-swap` (`flash-next-uncensored-v2` on Gufo `0.35.0`, or the `W1-W3` winning writer) injecting ASR transcripts, speaker IDs `(S1)/(S2)`, and BPM into the prompt context.
   - Runs `beta7_convert.py` + strict pre-flight validator (`U56 Decision #1`): **zero** `integrated_multimodal_description:` / `overall_soundscape:` / `non_diegetic_music:` headers, **zero** Markdown leakage, **zero** policy/governance disclaimer words, valid `<d>[English] ...</d>` / `<scenetrans>` / `<cutoff>` / `[Shot 1]` (no timestamp) / `[Shot N] At MM:SS.mmm`, and **omits `<Picture N>` tags** for subjects supplied via `ComfyUI-MiniMaxH3Mod` RefMods (`mod_1..mod_8`).
3. **Stage 3 — Frozen-Graph Render Execution (via `pi-job` / AlienPC `comfyui_auto` `:8446`):**
   - Builds a per-run frozen `request.api.json` copy from the live `U55` / B2 templates (never mutating production templates).
   - Respects `flock` (`gpu-render.lock`), `gpu_lock_gate.py`, and `P4.11` 6-digit `ntfy` approval codes before queuing on AlienPC.
   - Optional RTX 2x upscale via live `pi-job upscale` (`run_queue.py --upscale-only`).
4. **Stage 4 — Hard-Cut Assembly & Records:**
   - Join approved clips using **hard cuts** (no crossfades, zero `capsule-cinema` dependency): use `ffmpeg -f concat` hard-cut muxing from the manifest order (or `rea-video drive OUT_DIR --join` specifically when running the motion-drive `drive/results.json` workflow; note `rea-video assemble` is for `capsule-cinema` `remake/results.json` and is not mixed with `drive`).
   - Run `pi-job upscale` (`RTXVideoSuperResolution` 2x) on final clips so `sync-renders` publishes them to the QNAP `renders` share (`/srv/renders`) and PixlStash, and record seeds/timings/notes in `evo-x3` records.
