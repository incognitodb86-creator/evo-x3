## Build one request
    C:\AI\director\.venv\Scripts\python.exe C:\AI\community\scripts\make_b2_request.py \
      --template C:\AI\community\templates\b2_refmod.api.json \
      --refmod <installed refmod name> \
      --arm-dir <run dir>\<tag> --prompt-file <txt> --seed <n> \
      --prefix community/<run>/<tag> --frames <n>

--size 768x1344` submits it, and `comm.guard_ok` (the adults-only prompt check) runs before every POST.
`--frames` must equal `c0.length` and be passed to `run_queue.py` / `run_graph_job.py`.
