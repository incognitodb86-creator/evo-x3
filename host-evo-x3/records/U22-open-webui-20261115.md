## First sign-up (Derrick does this; do not skip)
Official hardening behavior: "Signup is open only until the first user registers, who becomes the administrator. After that, signup is automatically disabled. No manual configuration is needed for this behavior." `DEFAULT_USER_ROLE=pending` is already set as a safety net if signup is ever turned back on.

Exact steps:
1. From a device on the tailnet, open `https://evo-x3-1.tailf242b2.ts.net:8443`.
2. Choose **Sign Up** (not Sign In).
3. Create the account with your email and a password. That first account is automatically promoted to admin, and Open WebUI automatically sets `ENABLE_SIGNUP=false`.
4. After you are in, confirm it is off: **Admin Panel → Settings** (Authentication / Enable New Sign Ups). If it is still on, turn it off there.
5. Do this promptly. Until you sign up, the first account to register becomes admin (the official first-run bootstrap window). The UI is tailnet-only, which narrows that window, but it is still open until you create the account.

Do not set `WEBUI_ADMIN_EMAIL` / `WEBUI_ADMIN_PASSWORD`; those would have created the admin automatically, which was not requested.

Note: the official image `start.sh` execs uvicorn with `WEBUI_SECRET_KEY` on the container process argv, so a root `systemctl status` / `/proc` listing can show it. The key is not in the Quadlet file. Rotating it later logs everyone out.
