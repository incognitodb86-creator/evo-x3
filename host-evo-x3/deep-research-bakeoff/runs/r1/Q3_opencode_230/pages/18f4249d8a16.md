# Background Subagents by Default
Subagents now return immediately, continue in the background, and report back whenever they become idle. You can keep working in the parent session while multiple subagents run concurrently. #63382
## Quieter Transcripts by Default
The TUI now summarizes each run of tool calls and thoughts into one collapsible activity row, so the answer is easier to follow. To see every step again, set Verbosity to medium or high in settings, or set session.verbosity in your TUI config; an existing setting is kept. #63207
## Jump to an Earlier Prompt
In the desktop app, open Jump to message from the command palette or press Cmd+Alt+G ( Ctrl+Alt+G on Windows and Linux) to search prompts across the current session and jump directly to one. #63585
## Improvements
Core Added experimental support for MCP events, behind the mcp_events flag. #63254 #63261 #63269
- Core Shell commands now survive server handoffs and keep their output when interrupted.
- Core Added experimental support for moving a shell command to the background when its timeout expires, behind the shell_timeout_background flag. With the flag on, an explicit timeout on a background command stops it. #63024 #63703
- Core Local Windows shell commands now run through the process daemon.
- Core Added support for freeform tool input on compatible models.
- Core Added LM Studio decision-model support.
- Core Agents are now told when their session is a fork. Thanks @hasta84. #63235
- Core Tool output truncation now keeps the beginning of the output and preserves a usable preview if the full output cannot be saved.
- Core Tail reads no longer load the entire file into memory.
- Core Providers can present a client certificate for gateways that require mutual TLS. Set settings.tls with cert , key and an optional passphrase on the provider; values accept {file:} and {env:} like apiKey . #61832
- Core When a subagent goes idle while its own background work is still running, its report to the parent now says it is still running, so the parent waits for the final report instead of treating the partial answer as done. #63675
- Core Code Mode gets simpler structured results from file and skill tools: write and edit return their confirmation as a string, patch returns an empty result, and skill returns the skill's directory and content. #63616 #63635 #63618 #63623
- Terminal Session IDs found in messages can now be opened directly.
- Terminal Activity tabs are clickable and open the correct view.
- Terminal Shell mode has its own prompt color under the new designs.
- Desktop Added the experimental Recent sessions sidebar, with cross-server recency, local pins, reordering, and standard session-row actions.
- Desktop Recent sessions are limited to the last seven days and 30 rows, and can be hidden or muted.
- Desktop Added an experimental customizable sessions sidebar.
- Desktop Mermaid diagrams can now be maximized for zooming and panning. #59250
- Desktop Added Alt+Enter to place a follow-up first in the queue and Mod+Enter to steer the next queued prompt.
- Desktop Holding the modifier key now shows tab shortcut numbers.
- Desktop Each server’s terminal shell can be selected from its menu.
- Desktop Added a free-limit panel in place of the composer when applicable.
- Desktop Session IDs are easier to find and copy.
- SDK Event subscriptions can now receive experimental.mcp.event events from MCP event subscriptions.
- SDK Model capability schemas now advertise supported freeform tool-input formats.
- SDK Session throughput is now measured from the first streamed token.
- SDK Session creation documentation now clarifies the parentID field.
- Extensions Promise-based tools can cooperatively stop through ToolContext.signal .
- Extensions Added the experimental session.fork hook.
- Extensions Promise plugin cleanup failures no longer prevent subsequent plugin replacements.
- Extensions @opencode/plugin/effect now exports Tool , so an execute.before hook can reject a call with Tool.Error without importing @opencode/schema/tool . #63698
