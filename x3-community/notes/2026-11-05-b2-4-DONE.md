placeholder `51083002`, while `prompt.txt` (2,702 B) carried the run's built prompt: the two
records disagreed. Cause: in the `two-pass-parody` branch the code re-read the raw template file

fields (prompt, seed, prefix, frames). Fixed in `build_parody_request`: the template branch now
uses the graph that `make_b2_build()` already produced from the template (per-run fields applied)
and only verifies it at the run's dials; the regenerate-from-`b2.api.json` fallback is unchanged.

`c0.length` 124. Pinned by new asserts in
`test_builder_two_pass_parody_uses_the_template_and_records_the_dials` (seed, prefix, prompt equal,
