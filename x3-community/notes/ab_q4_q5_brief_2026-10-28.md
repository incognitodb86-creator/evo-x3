## Honest costs
- **Variables per arm:** A = build path + VSA range (2 vars vs v2); C = steps only (clean vs A); B = upscaler weights + pass-2 recipe + VSA range vs v2 (3 vars) and A-vs-B carries build path + VSA range (2 vars). A-vs-C is the only single-variable pair.
- **Expected rate:** A ≈ 1.48 s/frame (~6 min); C ≈ 1.5× A (~9 min); B ≈ 4× cheaper pass-1 steps (0.26 MP) + 4 full-res steps ≈ ~5 min; RTX 1.2× on 243 frames at 922×1613 is **unmeasured** (likely ~2-4 min/clip); crf-18 slow encode ~1-3 min/clip. Total GPU ≈ 35-45 min plus post.
- 12 steps on an 8-step turbo is off-dial; the model card's own line is 8-step TURBO. The official docs recommend 20-25 steps for reference fidelity (audio 12+), and C at 12 is the cheap probe of that claim, not its full form.
- RTX 1.2× is a pixel-space enhancement, not generation: it sharpens edges, it cannot add detail that sampling lost, and it can sharpen artefacts along with faces.
- Prompt content is fixed at v2, so none of these arms can fix the 8-10 s low-motion window.
