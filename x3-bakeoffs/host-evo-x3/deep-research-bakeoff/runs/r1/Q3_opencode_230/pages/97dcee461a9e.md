- Nov 13, 2026 v2.3.0
## Background Subagents by Default
Subagents now return immediately, continue in the background, and report back whenever they become idle. You can keep working in the parent session while multiple subagents run concurrently. #63382
### Quieter Transcripts by Default
The TUI now summarizes each run of tool calls and thoughts into one collapsible activity row, so the answer is easier to follow. To see every step again, set Verbosity to medium or high in settings, or set session.verbosity in your TUI config; an existing setting is kept. #63207
### Jump to an Earlier Prompt
In the desktop app, open Jump to message from the command palette or press Cmd+Alt+G ( Ctrl+Alt+G on Windows and Linux) to search prompts across the current session and jump directly to one. #63585

- Nov 10, 2026 v2.2.7
## GitHub Copilot Auto
Pick Auto in the model picker when your Copilot account has an Auto pool, and Copilot's router chooses the model for each session at the Auto discount. If routing fails, OpenCode falls back to the account's default chat model. #62997
### Side Panel Tab Shortcuts
Right-click a side panel tab and choose Close tabs to the right . ⌘W now closes side panel tabs wherever focus is, ⌥⌘W or Ctrl+Alt+W always closes the session tab, and ⌘⇧T reopens the last closed tab of either kind where it was. #62922
### Mark Sessions Read or Unread
Open the menu on a tab, Home row, project row or inbox card and choose Mark as unread to keep its dot until you next visit. #62889
### Breaking changes
#### @opencode/ai : ImageResponse.image is removed
This affects code that imports @opencode/ai directly. Read response.images[0] instead of response.image . #63011
#### SDK: fewer endpoints wait for plugins to load
On a Location that is still loading plugins, agent.list returns the agents loaded so far, and integration.list , usage.limits , vcs.init , rpc.call and artifact.* no longer wait up to 5 seconds. Entries and actions that a plugin provides appear when it finishes loading, so refresh on the matching *.updated event. Model, provider, generate.* , voice.* and websearch.query endpoints still wait. #62796 #63040

- Oct 30, 2026 v2.2.5
## Worktree and Shell Mode Shortcuts
Press ⌘⌥O on macOS or Ctrl+Alt+O on Windows and Linux to choose a worktree, and ⌘⌥B or Ctrl+Alt+B to choose its base branch. ⌘⇧X or Ctrl+Shift+X now toggles shell mode in the composer. #60713
### Send Quotes From the Comment Popup
Hold ⌘ or Ctrl in the quote popup to turn its checkmark into send, or press ⌘Enter or Ctrl+Enter , to send just that quote and comment while leaving the rest of the composer untouched. #60640
### Percentage Compaction Buffer
Set "compaction": { "buffer": "20%" } in opencode.json to keep a share of each model's context window free, so one setting fits models with small and large windows. Token counts still work. #60647
### Improvements
Core When read misses because a folder is missing, the error names that folder and the nearest one that exists. #60688

- Core Calls to a tool named bash now run as shell instead of failing, with the same permissions. A plugin tool actually named bash still takes precedence. #60687
- Desktop Added flat input surfaces and a compact input size. #60598

## Persistent Desktop Terminals
Desktop terminals now belong to the session, survive server restarts with their scrollback, and stay synchronized with the TUI and other windows. Renamed terminals also keep their names across restarts. #60346
### Publish Interactive Artifacts
Enable "experimental": { "artifacts": true } in opencode.json to let agents publish, update, and serve HTML or static artifacts through the built-in local provider or plugin-provided storage. #60351
### Guided Claude Agent Setup
Select Claude Agent from the provider picker to copy claude auth login , install Claude Code, and verify the connection before continuing to model selection. #60603
### Choose a Base Branch Quickly
While creating a worktree, open Choose base branch with ⌘⌥. on macOS or Ctrl+Alt+. on Windows and Linux. The command is also available in the command palette and Settings › Shortcuts. #60579

## Use Claude Code in OpenCode

### Breaking changes
#### TUI plugins require OpenTUI 0.8
@opencode/plugin now requires @opentui/core and @opentui/solid 0.8.0 or later. In OpenTUI 0.8, a ScrollBox's wrapper , viewport , content , and scrollbars are facade objects instead of renderables, and a custom RenderContext must implement clock and onAnimationTick . See the OpenTUI 0.8.0 release notes . #60385
#### Managed policy: integration.use covers integrations only
integration.use now controls which integration accounts can be used, and the new mcp.use , skill.use , and plugin.use actions control MCP servers, skills, and plugins. Rules with the old mcp: , skill: , and plugin: resource prefixes are converted automatically, but a bare integration.use rule no longer applies to MCP servers, skills, or plugins. #60315

Run /goal <objective> in the TUI or Desktop to let the session continue until a reviewer confirms the objective is met. Use /goal pause , /goal resume , or /goal clear to control it. #59437

### Breaking changes
#### @opencode/ai provider removals and renames
These changes affect code that imports @opencode/ai directly. They don't change the CLI, Desktop, or the HTTP API. The fal, Black Forest Labs, Replicate, and Stability providers are removed, along with their ./providers/fal , ./providers/black-forest-labs , ./providers/replicate , and ./providers/stability entry points.
- Five legacy entry points are removed. Import the nested paths instead, which 2.2.0 already exports: ./providers/amazon-bedrock-mantle → ./providers/amazon-bedrock/mantle , and ./providers/google-vertex-chat , -interactions , -mistral , and -responses → ./providers/google-vertex/chat , /interactions , /mistral , and /responses .
- Each provider's configure() input type is now named Config , for example Groq.LanguageModelOptions → Groq.Config , and model() settings are optional when every setting is optional. #59977 #59506 #59765

Instead of editing the system prompt and busting the prompt cache, each change is added as a small update at the next step. The entries also survive compaction and reverts, and they don't start an extra model turn. #56550

### Breaking changes
#### @opencode/ai root is now the Promise API
@opencode/ai now works like @opencode/sdk and @opencode/client : the package root exports the Promise API, and the Effect API moved to @opencode/ai/effect . @opencode/ai/promise is removed, and the wildcard subpath export is replaced with an explicit list of provider and protocol entry points.
-import { AI } from "@opencode/ai/promise"
-import { LLM } from "@opencode/ai"
+import { AI } from "@opencode/ai"
+import { LLM } from "@opencode/ai/effect" #58847 #59183
#### The OpenCode GitHub Action is removed
The OpenCode GitHub Action is no longer published. Remove it from your workflows. #59032
#### TUI plugins require OpenTUI 0.7
@opencode/plugin now requires @opentui/core and @opentui/solid 0.7.0, up from 0.6.8 or later. Plugins that depend on OpenTUI 0.6 fail to install until they upgrade. In OpenTUI 0.7, custom renderables read their hooks from their class at construction: assign renderBefore , renderAfter , and onLifecyclePass in the constructor instead of as class fields, call refreshHooks() after adding a hook by reflection, and replace defineNativeIntegration() with a static nativeIntegration declaration. See the OpenTUI 0.7.0 release notes . #59295
