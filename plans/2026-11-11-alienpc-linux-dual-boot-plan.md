Sources: prior fleet plan 2026-10-19; NVIDIA/Strata "not WSL2" (README opened 2026-11-11); Ubuntu NVIDIA packaging practice; Arch/NTFS Fast Startup advice from the Oct 30 note.

## What can still affect Windows (even on a separate drive)

- **BIOS boot order.** If Linux is first, a power cut boots Linux and the Windows Comfy/Forge/Grok Bot local-exec stack is offline until someone picks Windows. Mitigation: Q3 settled as Windows default until U10 + a later yes. `grub2/update_nvram=false` plus a BootOrder recheck after Linux or BIOS updates (P1-5).
- **Secure Boot / BitLocker.** Enrolling a MOK key, turning Secure Boot off, flipping a "3rd-party CA" switch, or a fwupd db/dbx update (including the 2026 Microsoft UEFI CA 2023 rollover that Ubuntu shims after June 2026 need) can change TPM PCR 7 and prompt for the BitLocker recovery key. Vaultwarden on the QNAP has been down since Nov 6 (relayed Nov 9), so a Vaultwarden-only copy is not enough. Mitigation: an **offline** key copy whose **protector ID** is verified in U2; `Suspend-BitLocker -MountPoint C: -RebootCount 0` before any of those changes; `Resume-BitLocker` after the first good Windows boot. Prefer Ubuntu's signed `linux-modules-nvidia-*-open` / `ubuntu-drivers` packages so Secure Boot can stay on and a MOK is not required.
- **Fast Startup and hibernation.** Must be **off** in Windows or Linux NTFS mounts of C: are read-only or unsafe. This is a reversible Windows setting (`powercfg /h off`, Fast Startup unticked, then a full **shut down**). This plan **never mounts C: from Linux**, but Fast Startup still matters if anyone later tries. Re-check it after Windows updates (they can turn it back on).
- **Do not shrink, format, or install onto C:** D: and E: are USB — not install targets. E: may be used as a **staging** disk for a model copy and a config backup.
