## 2-pass parody (B2-4, `b2_parody_2pass.api.json` — not in repo (retired; see TQ1))

> **Status (2026-11-19):** `b2_parody_2pass.api.json` is **not in repo (retired; see TQ1)** — replaced by the RefMod-only
> 2-pass candidates `oc_guide_2pass.candidate.api.json` and `oc_ref_2pass.candidate.api.json` (documented in
> `CANDIDATES-TQ.md`). Notes below are kept for historical reference.
One command shape (dry-run, nothing is queued):

    C:\AI\director\.venv\Scripts\python.exe C:\AI\community\scripts\parody\submit_parody_run.py --name <celeb> --description <bio> --scene <scene> --dialogue <line> --seed <n> --frames 124 --graph-mode two-pass --pass1-lora-strength 0.0 --pass2-lora-strength 1.0 --dry-run

`--pass1-lora-strength` defaults to **0.0**, `--pass2-lora-strength` to **1.0**. At 0.0 the pack's loader patches
nothing and passes the model through (`nodes.py:179-191`), so pass 1 samples the base beta7 model and the native
voice stays intact; above 0.0 a `reflora_p1` loader is inserted on the pass-1 model line. The graph is
`b2.api.json` + `refmods`/`refapply` (retention 1.0) + `reflora_ref` (lora_strength 0.0, refs only) ->
`reflora_apply_1` (the one conditioning injection, feeding `ag0` AND `ag1`) + `reflora_p2` (the pass-2 dial,
`attach_to_model=False`, `components="Visual"`, clip given) on `s1_guide`/`p2sched`. `c0.clip` stays the raw CLIP
loader, `dec_a.samples` stays `["s0_sep",1]` (audio from pass 1), every other node is byte-identical to
`b2.api.json` (`reflora.frozen_diff_2pass` is the guard, `verify_parody_2pass_graph` the shape check).

`--unet <file>.safetensors` swaps the model between the two beta7 checkpoints on disk: default
`10Eros_Max_h3_8stepTURBO_beta7_int8HQ.safetensors`, the only other accepted value
`10Eros_Max_h3_8stepTURBO_beta7_activation_learned_HQ.safetensors`. Bare filename, no path, no download; anything
else raises before a file is written. The swap is written into the built request only, the template keeps the int8HQ
placeholder. **The model swap is the only dial that may differ between A/B arms**; the per-pass LoRA dials are the
arms' other knobs and are recorded in `_render_order.json` and `assets.json`.

`b2.api.json` and `b2_refmod.api.json` are hash-locked by `scripts\parody\test_longclip_baseline.py:29-33` and are
never edited. `b2_parody_2pass.api.json` is **not in repo (retired; see TQ1)**; historically it was derived via
`reflora.derive_parody_2pass_template(b2.api.json)`. Per-run fields (`noise.noise_seed`, `save.filename_prefix`,
`img.image`, `c0.prompt`) keep the b2 example values in the file and are set by the builder for each run.
