## The 15-second frame math (measured, not assumed)

The item says 15 s = 361 frames. **361 is not reachable on H3.** Measured in the live schema dump
`notes/ali173_b2_object_info_full.json`:

- `MiniMaxH3ReferenceToVideo.length`: `step 17`, default 124, tooltip "124 = ~5s, trained range is ~124-362".
- `MiniMaxH3GuidedContinuationWindow.overlap_frames`: "must satisfy 17k+5" (default 22),
  `extension_frames`: "must be a multiple of 17" (default 119).

Legal frame counts are `17k+5`. 361 = 17*21+4 → illegal; **362 = 17*21+5 = 15.0833 s** → the 15-second target.

Shape used: 124 + 119 + 119 = 362, i.e. the published continuation pass run twice
(sampled windows 124, 141, 141 = 406 sampled frames; 22 hidden overlap + 119 new per continuation).
Source of the method (installed, published, not built here): `ttulttul/ComfyUI-Minimax-H3-Continuation`
v0.6.3 at `ComfyUI/custom_nodes/comfyui-minimax-h3-continuation` (git `e1768d5`), README
"Required connections" 1-6 + "Alignment rules" (overlap 22, extension 119, window 141) and
"cumulative latent storage grows after every append". Its shipped `example_workflows/guided_continuation.json`
is a 2-pass workflow (30 nodes, one of each continuation node), so the 3-chunk chain is that published
pass repeated against the appended cumulative latent. No new node, no new extension.
