## Assumptions (the smallest reading of each rule)
1. A body must be exactly 768x1344 (9:16) or 1344x768 (16:9). No derived resized bodies are made (this is stricter than the plan, see audit A-P1-5).
2. Cast, characters, target, angle and adult flag come from the annotation CSV. A missing or inconsistent annotation makes the still UNSURE, and any UNSURE stops the picker before picks.csv is written (it is never treated as single cast).
3. E10, the real-named IDs and the 10-17 run list (by sha256, path or basename) are excluded, and so are folders whose names start with "_". A co-star who is not approved rejects the panel.
4. The canary is a single-cast front still at an exact size, first in seeded order. It is not counted in the 30.
5. The head crop box is "PENDING_MA". The driver stops if a crop is still pending (L-FULL uses the full approved still). The minimum head-crop size (256) and the B1 misalignment value (2.0) are NEEDS_DEREK config values and are never used as gates.
6. Allow-list classes are approved, derived and pose_skeleton. A Klein graph accepts approved and derived only. The scorer reads all three. Only flux_edit_run.py writes the list (static test). If the same sha256 appears twice, the first entry wins.
7. Image detector: only a test stub exists. Any verdict other than "adult", or any exception, stops the run. With no detector configured, the guard relies on the allow-list alone.
8. R6 is strict: a real row needs JOB start + JOB end ok with no error, timeout, SKIP or CLIP_SKIP. An eviction resubmits once as `<tag>_r1`, and the row counts if the base tag or `<tag>_r1` is real. A second eviction stops the run. comm.py never writes CLIP_SKIP; the driver only parses it.
9. Budget: (1800 − 420) / 181 = 7.62 s per unit against a 7.6 s rule. E8 = 2 units. Window 1 = L, E, CTRL (181 starts incl. canary). Window 1b = E8, L-FULL (121 starts, 181 units). The split check runs after 5 warm jobs.
10. Before the wake, the driver waits (up to 600 s) until llama-swap `/running` shows no model starting/busy/loading and no in-flight count. Then it unloads the LLMs. An unknown `/running` shape stops the run.
11. The live LoRA name comes from `/object_info/LoraLoaderModelOnly`, where exactly one option may end in the pinned filename. The local file is checked by name, size and full sha256 (49907a24…be16).
12. The template API JSON is generated by code, not exported from the UI. That breaks U11 step 1, and the template README logs it.
13. A usable panel for an arm needs at least one of its two seeds to pass all five checks. ORIG (the unedited still) is a blind code. show_original=False is the default. The output avoids the words KEEP and PASS (R5).
