# Strata — research note (local LLM / agent stack)

**Date:** 2026-10-11 (America/Chicago)  
**Scope:** Research only. No AlienPc touch (audit running). No installs.  
**Our setup (context):** RTX 5070 Ti 16 GB (Blackwell sm_120), Windows, llama.cpp **b11482**, Qwen3.8-**27B** Heretic GSQ-RCO IQ3_XXS-mtp @ 64K, Forge (Pi coding agent), Switchyard director/queue; recent look at Raymond Huang adaptive KV-streaming llama.cpp fork.

---

## Verdict (short)

**"Strata" almost certainly means [Niko1221/Strata](https://github.com/Niko1221/Strata)** — a narrow C++/CUDA/HIP **inference engine** that runs **Qwen3.8-Flash-Next (125B MoE, ~6B active)** on a gaming PC via expert caching (hot experts in VRAM, rest in RAM/SSD), MTP speculative decode, OpenAI + Anthropic APIs, and an optional **MCP server**. It is **not** a drop-in for the current Heretic **27B** + llama.cpp lane; it is a **parallel bigger-model path** that fits AlienPc hardware unusually well (official benches on RTX 5070 12 GB + CUDA 13 / sm_120).

## Top candidate deep dive: Niko1221/Strata

### What it does
- **One-model engine:** Qwen3.8-Flash-Next GSQ-RCO packs (Q2_0 / IQ2_XS / IQ3_XXS / IQ3_S), plus Coder / Swift 1.5 / Unsloth UD variants (see `docs/MODELS.md`).
- Keeps always-used dense path + hot experts on GPU; parks the expert set in **system RAM** (or maps from SSD in low-RAM mode); n-gram / PLE table on disk.
- **MTP** multi-token prediction speculative decode; chunked prefill with PCIe overlap; KV options `--kv int8` (default), `--kv q4_0` (tensor-core prompts on RTX 30+).
- Serves **OpenAI-compatible** `/v1` and **Anthropic** `/v1/messages`; optional vision; **MCP** tools to install/start/stop (`docs/MCP_SERVER.md`, `AGENTS.md`).
- Latest noted: **v0.1.38** (2026-10-03) → SourceForge also mirrors **v0.1.40** Windows zips. MIT. Uses parts of llama.cpp/ggml for formats, but is **not** a llama.cpp frontend.

### Windows + CUDA 13 + 16 GB Blackwell?
| Need | Status |
|------|--------|
| Windows 10/11 | **Yes** — `START-HERE.bat` / `UPDATE.bat` |
| CUDA 13 + RTX 50 (sm_120) | **Yes** — `strata-windows-x64.zip`: sm_75/86/89/**120** + PTX, CUDA **13.0**, driver **580+** |
| 16 GB VRAM (5070 Ti) | **Yes** — stated min ~12 GB (v0.1.38: even 6 GB can start with lowered reserve); more VRAM → more resident experts → faster |
| System RAM | **Critical:** 32 GB → Coder (or low-RAM mode); **48 GB** → Q2_0/IQ2_XS; **64 GB** → IQ3_XXS/IQ3_S. AlienPc brief assumes **64 GB DDR5** (unverified on Cos) — confirm before IQ3_XXS |
| Disk | ~80 GB free (model ~66–76 GB + MTP ~6 GB) |

Official speed (RTX **5070 12 GB**, Ryzen 5 7600, 64 GB RAM) — short chat / 128K write / 32K prompt read:

| Quant | Write (short) | Write @128K | Prompt read |
|-------|--------------:|------------:|------------:|
| Q2_0 | 94 t/s | 76 | 2,650 t/s |
| IQ2_XS | 79 | 63 | 2,090 |
| IQ3_XXS | 62 | 49 | 1,750 |
| IQ3_S | 53 | 46 | 1,620 |

Community (via Stackness): RTX **5090** ~179 t/s @4K, ~165 @128K (self-reported). HF community (shefowl hybrid GGUF on RX 7900 XTX): Strata **1.6–2.3×** their own Vulkan MoE fork on decode; ~6× faster prompt read vs that fork.

### What it replaces or adds (vs current stack)
| Piece | Effect |
|-------|--------|
| **llama.cpp b11482 + Heretic 27B** | **Does not replace.** Different model family (125B MoE Flash-Next vs dense 27B). Keep Heretic lane for Forge when you want the current abliterated dense model. |
| **Raymond KV-streaming fork** | Orthogonal. Strata has its own `--kv-resident` / `--kv-pool-tokens` / disk conversation cache PRs; not a llama.cpp fork. |
| **Inference backend for agents** | **Adds** a second localhost API (default `:8080`) Forge / Switchyard / Claude-Code-style clients can point at for Flash-Next. |
| **MCP** | **Adds** Strata MCP for install/lifecycle (not a general tool MCP). |
| Concurrency | **One request at a time** (vs llama.cpp multi-slot). Bad for parallel Switchyard workers; fine for one Forge session. |
| First start | Can freeze UI **1–3 min** while 35–55 GB experts load into RAM. |

**Fit summary:** Hardware fit is **excellent** (5070 Ti 16 GB + Win + CUDA 13 is the project's sweet spot). Product fit is **"try as bigger MoE coding/chat brain beside Heretic"**, not "swap Heretic off llama.cpp."

### Community / trust signals
- Rapid releases (~38 in ~9 days through early Oct 2026); active PRs (disk KV tier, kv-pool, prefill layer cache).
- Stackness (4 Oct 2026): positions Strata as the gaming-PC Flash-Next specialist among llama.cpp alternatives.
- Abliterated / hybrid GGUFs on HF explicitly document Strata as the intended runner (e.g. alesha-pro Strata-GGUF, shefowl hybrid).
- Caveats: single-model lock-in; self-reported benches; first-load RAM shock; no Mac; concurrency = 1.

## Concrete small test plan (after audit; do **not** run on AlienPc now)

**Goal:** Decide whether Flash-Next@Strata beats Heretic-27B@llama.cpp for Forge coding turns enough to justify ~80 GB disk + RAM residency.

**A. Install (when audit clear)**  
1. Confirm RAM ≥48 GB free for Q2_0/IQ2_XS (prefer **IQ2_XS** on 64 GB; **Coder** if only 32 GB).  
2. Clone/unzip Niko1221/Strata → `START-HERE.bat` → NVIDIA CUDA 13 engine → pick quant → wait for model+MTP.  
3. Bind `127.0.0.1:8080` with API key; do **not** expose LAN.

**B. Baseline (current, unchanged)**  
- Heretic Qwen3.8-27B IQ3_XXS-mtp, llama.cpp b11482, 64K, same KV settings as daily driver.  
- Metrics: **TTFT**, **decode t/s** at prompt lengths **4K / 32K / 64K**, **VRAM/RAM peak**, **tool-call JSON valid %** on 20 Forge-style turns, wall time for **one fixed coding task** (e.g. small SWE-ish edit: open file, patch, run tests).

**C. Strata arm**  
- Same prompts / same coding task via OpenAI client → Strata.  
- Quants to try: **IQ2_XS** (rec) then optional IQ3_XXS if RAM allows.  
- Flags: default `--kv int8`, MTP on (project default), context 32K first then 64K if stable.  
- Same metrics as B. Optional: `--calibrate` once (~15–30 min) after functional pass.

**D. Decision rules**  
- Prefer Strata for Forge if: decode ≥ current Heretic **and** coding-task pass rate ≥ Heretic **and** TTFT at 32K not worse than ~2× Heretic.  
- Keep Heretic as default if: Strata wins speed but fails tool/JSON or Coder-only quality outside English code; or RAM pressure fights ComfyUI/other apps.  
- Do **not** A/B against Raymond KV fork in this first pass (different question: long-context 27B vs big MoE).

**E. Out of scope for first test**  
OSDI Strata/SGLang, ro99/strata, Unsloth UD-Q4_K_XL (slow SSD-expert path), exposing beyond localhost.
