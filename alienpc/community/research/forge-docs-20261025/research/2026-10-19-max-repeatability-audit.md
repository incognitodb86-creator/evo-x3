## 1. What the community does (each with a source)
| # | Practice | Source |
|---|---|---|
| P1 | Save the graph via **File → Export Workflow (API)** and submit that JSON programmatically. The UI save format is only for re-opening in the editor. | https://docs.comfy.org/development/api-development/workflow-api-format |
| P2 | Run a saved API workflow from the CLI: `comfy run --workflow ./workflow.json` (async, prints prompt_id; `--wait` blocks; `--set` overrides values). UI-format JSON is auto-converted. | https://github.com/Comfy-Org/comfy-cli (README) |
| P3 | Stock server API: `POST /prompt` (validates, returns prompt_id or node_errors), `GET /history/{prompt_id}`, `GET /queue`, `GET /object_info` (node schema for offline checks). | https://docs.comfy.org/development/comfyui-server/comms_routes |
| P4 | Pin the ComfyUI version: `comfy update comfy --version 0.3.0` (checks out a tag), or `comfy install --version/--commit`. | https://github.com/Comfy-Org/comfy-cli |
| P5 | Snapshot custom nodes and their commit hashes: ComfyUI-Manager `cm-cli.py save-snapshot --output snap.yaml` / `restore-snapshot … --pip-non-url`; or `comfy node save-snapshot` / `restore-snapshot`. Pip packages are restored only with an explicit `--pip-*` flag. | https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/cm-cli.md · https://github.com/Comfy-Org/ComfyUI-Manager/issues/2008 · https://docs.comfy.org/manager/legacy-ui |
| P6 | One environment lock file: comfy-pack `.cpack.zip` records the ComfyUI commit, custom-node commits, pinned pip versions, Python version and **model sha256s** (no weights). `comfy-pack unpack` rebuilds it. | https://github.com/bentoml/comfy-pack · https://www.bentoml.com/blog/comfy-pack-serving-comfyui-workflows-as-apis |
| P7 | **Model manifest inside the workflow JSON**: `properties.models[]` = {name, url, hash, hash_type "SHA256", directory}. That's how official templates declare their models. | https://docs.comfy.org/specs/workflow_json · https://github.com/Comfy-Org/workflow_templates/blob/main/docs/SPEC.md · https://docs.comfy.org/interface/features/template |
| P8 | Start from the **official template** (Template Library → Video → "MiniMax H3 I2V"; JSON at `templates/video_minimax_h3_i2v.json`). Native canvas 1344×768; 17k+5 frame grid; default 20 steps, turbo 8. The I2V template opens at 1:1 / 0.4 MP, so set the AR and MP for finals. `first_frame` is stretched; `last_frame` is center-cropped. | https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native · https://github.com/Comfy-Org/workflow_templates |
| P9 | Reusable presets per shot type = **Subgraph Blueprints** (publish a subgraph to the Node Library, frontend ≥1.27.7). They can also be shipped as JSON in a `subgraphs/` folder. | https://docs.comfy.org/interface/features/subgraph · https://docs.comfy.org/custom-nodes/subgraph_blueprints · https://github.com/Comfy-Org/workflow_templates/blob/main/docs/BLUEPRINTS.md |
| P10 | **Embed the graph in every output.** Native SaveVideo writes `prompt` (the API graph) into the file's metadata, plus `extra_pnginfo` (the `workflow`) when the client sends it in `extra_data`. VHS Video Combine has `save_metadata`. CLI/API runs carry no `workflow` block unless the caller adds it. | https://github.com/comfyanonymous/ComfyUI/blob/master/comfy_extras/nodes_video.py · https://github.com/comfyanonymous/ComfyUI/blob/master/server.py (`workflow_metadata_from_prompt`) · https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite/issues/649 |
| P11 | Fixed seeds with `control_after_generate = fixed`, and log every param. `--deterministic` makes torch use deterministic kernels "when it can… might not make images deterministic in all cases". | https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/cli_args.py (line ~194) |
| P12 | One shared model folder via `extra_model_paths.yaml` (`--extra-model-paths-config`). Clones and envs point at it, no copies. | https://github.com/comfyanonymous/ComfyUI/blob/master/extra_model_paths.yaml.example · cli_args.py |
| P13 | LoRA card settings are part of the preset: HMNSFW AIO = Euler/Simple, 12 steps, shift 6, strength 0.5–0.9. HMMisDog = Euler/simple 8, shift 6. | https://civarchive.com/models/2834417?modelVersionId=3268303 · https://civarchive.com/models/2924146?modelVersionId=3308736 (already in `cos/research/2026-10-19-max-community-gap-check.md`) |
