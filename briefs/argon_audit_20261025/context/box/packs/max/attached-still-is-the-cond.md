---
title: When Derrick attaches a still, that exact file is the cond
applies_when:
  - Derrick attached an image this turn and the work makes stills, I2V or a movie cell from it
  - writing or reviewing a Max or Shorts plan that names a cond or seed image
tags: [max, cond, still, i2v, attached]
---

The attached file is the cond. Copy its path into the plan's `cond:` line in the same turn. A plan or brainstorm that bans that scene or names a different file is void unless Derrick named the other file himself. Short names such as "HC3", "ORC_BJ" or "P157" are not files. Do not start a seed until the `cond:` line holds that path.
