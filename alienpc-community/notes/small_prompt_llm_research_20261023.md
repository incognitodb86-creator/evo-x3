## The baseline to beat (Civitai H3 prompt writer)
- https://civitai.com/models/2967166 (`civ_2967166.json`, description verbatim): "LLM-based prompting (using Ollama) ... Vision capabilities. LLM can see your references ... NSFW support", 511 downloads / 22 thumbs, creator vamorand. Its LLM setup = **Qwen3.8-27B-Heretic-Abliterated-Uncensored** `RVN-Q5_K_M-multilingual-vision.gguf` + `mmproj-Qwen3.8-27B-Q8_0.gguf` (https://huggingface.co/0bserverx/Qwen3.8-27B-Heretic-Abliterated-Uncensored-GGUF, 1,006,464 downloads / 742 likes), Ollama Modelfile `FROM ... ADAPTER ...`, workflow default context 49,152 and "at 32768 context the buffer takes roughly 2 to 3 GB of VRAM ... at 65536 4 to 6 GB", "If you have 32Gb VRAM, you can use this Q5". Author's own caveat: "You should be able to run this workflow with any LLM that can analyze images and runs with Ollama, but I can't guarantee that smaller ones will be able to follow instructions well enough."
- On our box: 16 GB GPU, H3 beta6 int8 resident, and llama-swap keeps ComfyUI and the LLM in one **exclusive group** - a 27B Q5 (~17 GB + 2-6 GB context) never coexists with H3. So the Civitai writer's own recipe is not runnable here as-is; that is exactly why the small-model question matters.
- The official rewriter: https://huggingface.co/lightx2v/MiniMax-H3-Prompt-Rewriter-LoRA (187 likes) = LoRA on **Qwen3.6-27B**, text-only T2VA, output fields `integrated_multimodal_description: [Shot 1] ...`, `overall_soundscape:`, `non_diegetic_music:` (the same sound-prompt fields our v2 prompts use). Its roadmap: FL2VA and **Ref2VA are not done**, and "This release supports text-only T2VA prompt rewriting; it does not consume images, videos, or audio references." Card also: MiniMax's hosted "Context-IR" is the closed service it approximates; their gallery shows rewrite > no-rewrite and > base-model rewrite.

## RECOMMENDATION (one)
Run **row 1: Qwen2.5-Omni-7B (ggml-org/unsloth GGUF, Q4_K_M/Q8_0) + the lightx2v/pytraveler Omni Prompt-Rewriter LoRA (Q8_0, 343 MB), task = Ref2VA, greedy, in the MiniMax-H3 Prompt Rewriter ComfyUI node** - it is the only found model trained for Ref2VA (six fields, and `subject_definitions` + `overall_soundscape` are exactly the wording our R4-R9 prompts hand-write), it is 7B at ~9 GB VRAM so it fits the 16 GB card that the 27B Heretic recipe (Q5 + 2-6 GB context) cannot, and it *looks at* the reference stills and *listens to* the reference audio instead of having them described to it. Fallback if it refuses a scene: the same node on the `mradermacher/Qwen2.5-Omni-7B-abliterated-GGUF` base, then row 3 (HauhauCS 9B writer, the pack's NSFW pick). Two hard rules for our loop: it is a **prompt writer, never a judge** - it must never be shown a generated frame (no vision judge on explicit output); and it shares the GPU with H3 through llama-swap's exclusive group, so the pass runs as its own script call (write prompt -> queue graph) with the ledger line in notes\bakeoff_gpu_ledger.md.
